# I-AM Sovereign Runtime

Welcome to **I-AM**, a sovereign, local-first, cryptographically self-contained runtime designed to operate entirely on your device. It offers you control over your **identity**, **intelligence**, and **memory**, free from external dependencies or centralized systems.

This runtime is more than an application — it's an extension of your **presence**, secure, private, and evolving.

---

## 🚀 Features

### Sovereignty at Core:
- **Content-Addressed & Local-First**: All data and operations stay on your device, ensuring privacy and autonomy.
- **Ed25519 Sovereign Identity**: Generates and uses a local cryptographic identity (`did:key:`) that never leaves your device.
- **Immutability and Chain of States**: Cryptographically linked state changes ensure data irreversibility and auditability.

### Runtime Highlights:
1. **Presence Dashboard**: Visualize your runtime states such as token balance, sovereign DID, and memory depth.
2. **Sovereign Identity**: Your DID and keys are stored securely on your device, with options to export or clear data anytime.
3. **Chat with Local Intelligence**: An integrated LLM backend powered by **Ollama** for secure and local conversations.
4. **Forge Mode**: A competitive evolution game where you and an AI develop runtime features.
5. **Content Resolver**: Resolve and view local `iam://` or `ipfs://` paths securely.
6. **IPFS Integration**: Pin runtime content to IPFS through a local Kubo instance, or export bundles for decentralized storage.
7. **Starfield Animation**: A mesmerizing visual background that reacts to the dark/light mode toggles.

## 🛠️ Technologies Used

### Front-End:
- **HTML5/CSS3**: Base structure and styling using Tailwind CSS with custom themes.
- **JavaScript**: Vanilla JS powers interactivity and runtime behavior.

### Local-First Cryptography:
- **Ed25519 Key Pairs**: Sovereign identity through `did:key` specification.
- **SHA-256 Cryptographic Hashing**: Ensures state immutability and content linking.
- **Base58 Encoding**: Human-readable compressed identifiers.

### Backend & External:
- **Ollama**: Optional local LLM backend for advanced AI functions. 
- **Kubo IPFS Node**: For decentralized content pinning and bundle distribution.

## 🖥️ How to Use I-AM

1. **Run Securely**:
   - Access I-AM in a secure context (`https` or `localhost`) to leverage local cryptography features.

2. **Navigating the Interface**:
   - **Dashboard**: Overview of memory depth, sovereign identity, and state.
   - **Forge**: Compete with local AI to propose features or improvements.
   - **Content Resolver**: View `iam://` or `ipfs://` addresses seamlessly.
   - **Deploy**: Pin your runtime state to IPFS or export for external hosting.

3. **Dark/Light Mode**:
   - Easily toggle between "Cyan" and "Magenta" themes.

4. **Data Management**:
   - **Export Identity**: Save your current sovereign state as a JSON file.
   - **Wipe State**: Clear all data irreversibly from your device.
